# Changelog

## [0.2.0](https://github.com/sgjholt/SpecMod/compare/v0.1.1...v0.2.0) (2026-08-23)


### ⚠ BREAKING CHANGES

* MultitaperEstimator.adaptive and TransformConfig.adaptive now default to False. Adaptive weighting collapses for off-centre transients, and a seismic arrival in a refined window is one.
* modules move to src/specmod/ and are renamed to snake_case (Spectral -> spectral, PreProcess -> preprocess, ModelGuess -> model_guess).
